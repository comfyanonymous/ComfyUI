## Usage Tips

### General Guidelines
- Eye LoRAs work well at low strengths (0.3-0.6)
- Can stack multiple eye LoRAs at reduced strengths
- Combine with face/skin detail LoRAs for best results
- Works with all FLUX checkpoints

### Recommended Combinations
```
<lora:Eyes_FLUX:0.5>
<lora:flux_realism_lora:0.7>
<lora:Flux_Skin_Detailer:0.6>
```

### For Portraits
- Use with close-up or portrait framing
- Add "detailed eyes, eye focus" to prompt
- Lower CFG (1-4) for more natural look
