## Description

Ha-eun is an experimental character LoRA from "The Asian Girl Next Door" series (same series as Mi Cha). Created using single-image training technology (beta). Features an 18-year-old Asian woman with punk/urban aesthetic.

### Key Features
- Brown eyes filled with joy and excitement
- Extravagant eyelashes
- Black hair
- White/pale skin
- Punk/urban style
- Confident, serene expression
- Slight smile

### Typical Outfit
- Black dress
- Black boots with skull buckle belt
- Black choker necklace
- Black bra/shirt
