## Description

Modified Flux.1 Dev checkpoint with enhanced Asian character effects. The creator describes it as: "Modified the original Flux model to add more Asian character effects" (修改原版Flux大模型，加入更多亚洲人物效果).

FP8 quantized format at 11 GB - fits in moderate VRAM while maintaining good quality for Asian and general character generation.

**Key features:**
- Enhanced Asian facial features and skin tones
- FP8 quantization for reduced VRAM usage
- Good for both portrait and landscape generation
- Works with standard UNETLoader
- No trigger words needed
