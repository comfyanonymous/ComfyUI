## Description

Better poses for pulling top (or bra, shirt, dress or sweater) off over the head. Configurable LoRA - requires specific trigger words for each clothing type.

**Other versions available:**
- PulledTopOff (Over Head) XL - for SDXL
- PulledTopOff (Over Head) Pony - for Pony

### Trigger words

| Clothing | Trigger | Prompt addition |
|----------|---------|-----------------|
| Shirt | `po_shi` | `pulled <color> shirt off` |
| Top | `po_top` | `pulled <color> top off` |
| Dress | `po_dre` | `pulled <color> dress off` |
| Bra | `po_bra` | `pulled <color> bra off` |
| Sweater | `po_swe` | `pulled <color> sweater off` |

**Additional for bra:** Can use `presenting bra` for holding the removed bra.

### Prompt structure
```
putoof, <clothing_trigger>, <state after removal> <remaining clothes> pulled <color> <clothing> off ...
```

**Important:** Describe the clothing AFTER the item is pulled off:
- Pulling off bra → describe girl as `topless`
- Pulling off dress → describe girl as `naked` or `in panties`
- Pulling off shirt/sweater → can describe remaining bra
